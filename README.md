# SnapFlow

从 [ShareX 21.0.0 正式版](https://github.com/ShareX/ShareX/tree/v21.0.0) 裁剪的普通/滚动截图程序。保留正式版的 **WinForms 选区、窗口与控件检测和滚动捕获实现**；在原始逐行拼接实现上修复固定悬浮控件干扰，并修复滚轮输入偏离所选区域及零滚动误报成功的问题。

## 运行

完整解压 `SnapFlow-win-x64.zip`，打开其中的 `SnapFlow.exe`。工作区程序位于 `dist/SnapFlow/SnapFlow.exe`。适用 Windows x64，需要安装 .NET 9 Desktop Runtime。保留同目录全部 DLL 和语言资源。

这是非官方裁剪版本；版权与出处见 [NOTICE.md](NOTICE.md)。

SnapFlow 当前版本为 **V1.0.0**；文件属性“产品版本”为 **1.0.0**，文件版本为 **1.0.0.0**。来源项目的 ShareX 21.0.0 为上游基线版本，与 SnapFlow 自身版本分别记录。普通截图与滚动截图统一使用主界面右侧预览，滚动完成、停止或取消选区后自动返回主窗口，不再停留在独立结果窗口。主界面的复制和保存操作使用完整分辨率原图；显示缩放不改变图片像素。

此前的动画优化继续保留：鼠标或空格键按下时立即反馈，悬停和开关使用无回弹、可反向中断的弹簧过渡；图片预览立即显示，再做轻微淡入。深色页面过渡快照中语言下拉框的颜色修正继续保留，不改变实际下拉框。保留滚动拼接、快捷键、设置格式与 WinForms 框架；此前已将截图结果交给主窗口；区域与窗口选择合并为一个入口；独立编辑窗口复用本地 ShareX 裁剪与多格式导出逻辑，本轮精简为手动裁剪、标注和五项基础输出操作。

设置页保留语言选择：跟随 Windows，或手动选择 24 种现有语言。保存后立即生效，取消则保留原语言；默认在启动时读取 Windows 显示语言并匹配现有语言包。新增主界面与设置页提供简体中文、繁体中文及英语译文，其他语言缺失的主程序文字回退英语；截图库与公共窗口复用原有语言包。此前的字体、图标、配色及窗口激活修复均保留。

界面保留 WinForms 和 Windows 原生窗口操作，参考 Apple 设计指南整理视觉层次与交互：左侧提供“区域/窗口截图”“全屏截图”“滚动截图”三个入口，右侧是主要图片预览区。预览面板、分组和按钮使用层次统一的圆角，并提供短暂的悬停、按下、图片显示与页面切换动画。右上角“设置”在当前主窗口内切换到设置页，不弹出独立窗口。保留 Windows 原生标题栏与窗口操作，高对比度优先使用系统颜色；不增加模糊效果或界面框架依赖。截图选区、原生截图、滚动捕获与拼接实现沿用上一版。

## 使用

- **预览缩放**：鼠标移到右侧预览窗格后，右下角浮动控件淡入，显示实时比例并提供 `−`、`+`；移出窗格后停留 300 毫秒再淡出隐藏，移回窗格会取消隐藏，移到控件上操作时保持显示。滚轮围绕鼠标位置放大／缩小，放大后可拖动查看；点击比例数字或按 `0` 恢复整图适配。
- **长图阅读**：点击右下角“适合宽度”，图片铺满可用预览宽度，滚轮改为上下阅读；支持拖动右侧滑块、Page Up／Page Down 翻页、Home／End 到首尾，Ctrl＋滚轮可重新缩放。再次点击“适合窗口”返回整图。新截图会重置视图；复制、保存和编辑仍使用完整分辨率原图。
- **区域/窗口截图**：同一按钮启动正式版选区，拖动框选或单击窗口/控件。
- **全屏截图**：截取整个桌面；普通截图在主窗口预览，可复制或另存为。
- **滚动截图**：沿用正式版单击/拖动选区；完成或停止后自动回到主界面右侧预览，用顶部“复制”或“保存…”处理图片。取消选区直接返回，保留上一次预览。左侧“滚动截图 · 设置”可调整原有滚动参数。

鼠标悬停文章正文或文件列表时查看高亮区域，确认地址栏、标签栏及无关侧栏在选区之外，再单击。开始后保持目标可见；程序会在每次滚动前把鼠标移回所选区域，选完后移开鼠标也能继续滚动。截图期间请等待完成后再操作其他窗口。

浏览器包含独立滚动文档时（例如学习通章节目录），在目标正文区域内单击。选区结束后会根据浏览器辅助功能信息，将范围收窄到鼠标所在的可滚动文档，排除外层固定导航；悬停高亮仍来自原版 Windows 控件检测。无法读取辅助功能或超过 1.5 秒时保留原选区，可重新拖动框选。检测只读取文档边界，不读取登录信息。

画面没有变化时会重新发送滚动输入，最多检查三次；从头到尾只有一屏且未检测到变化时，主界面底部会提示“未检测到滚动，仅获得一屏截图”，不再标记为成功。

学习通个人空间等页面存在较宽的固定侧边按钮。原版默认比较范围匹配失败时，会依次改用中央 70%、中央 50% 进行同样的逐行匹配；输出仍保留选区的完整宽度。进入这条匹配路径后，接缝位于重叠区域靠上的位置，用下一屏未被下方悬浮控件遮挡的内容接替旧画面。

默认参数与 21.0.0 正式版一致：启动延迟 300 ms、滚动间隔 300 ms、每次 2 格、默认不回到顶部。需要整篇文章时，先回到文章顶部，或在主界面左侧“滚动截图 · 设置”中启用“自动滚动到顶部”。选项保存到程序旁的 `SnapFlow.settings.json`。同目录存在旧 `ShareX - roll.settings.json` 时可继承；构建脚本也会继承本工作区旧发布目录中的设置，个人设置不放入分发包。

选区时按 Esc 取消；截图中按相同滚动快捷键，或从任务栏激活滚动截图窗口，即可停止。

| 功能 | 默认快捷键 |
| --- | --- |
| 区域/窗口 | Ctrl + Shift + A |
| 全屏 | Ctrl + Shift + F |
| 滚动 | Ctrl + Shift + S；被占用时尝试 Ctrl + Alt + S |

旧配置优先沿用原“区域截图”的快捷键；若区域快捷键未设置而旧“窗口截图”已设置，则继承旧窗口快捷键。合并后仅注册一个选区快捷键。主窗口底部显示实际注册结果。按钮始终可用；若滚动快捷键都被占用，可从任务栏激活滚动窗口停止。

### 编辑与导出截图

截图显示在主界面右侧后，点击复制、保存旁的 **编辑**，打开独立图片编辑窗口。窗口直接使用本地保留的 ShareX 21.0.0 编辑器，默认进入 **裁剪**，立即显示整张图片的边界与八个拖动点；拖动四边中点或四角向内调整，点击勾或按 Enter 确认，点击叉或按 Esc 取消本次裁剪。图片内部拖动不会重新框选。保留矩形、椭圆、画笔、箭头、文字、气泡、编号、图片、贴纸、鼠标指针、智能擦除，以及局部放大、模糊、马赛克、高亮和聚光灯。支持标注选择、移动、尺寸和样式调整、复制、粘贴、删除、叠放顺序与撤销／重做（Ctrl + Z / Ctrl + Y）；缩放和平移仅用于查看图片。

编辑窗口移除自动裁剪、整图尺寸与画布调整、旋转翻转、新建／打开整图、拼接、剪纸、图像效果、编辑器高级选项及帮助网页入口。剪纸快捷键 X 同时禁用；空格、波浪号和鼠标侧键不再触发编辑器中的截图操作。应用到预览、复制、保存、导出与手动裁剪保留。

点击 **导出图片…**，在保存对话框的文件类型中选择 **PNG、JPEG、GIF、BMP、TIFF**。导出使用原版图像编码器；导出后仍可继续编辑。工具栏的保存图标（Ctrl + S）可保存到当前导出路径。

点击 **应用到预览** 将编辑结果更新到主界面。应用、复制、保存和导出都会先确认当前裁剪边界；未处于裁剪状态时，也可按 Enter 应用到预览。关闭编辑窗口不会自动替换主界面图片；有未保存修改时沿用原版关闭确认。编辑基于原图副本，取消编辑保留原图；编辑期间暂停本软件的全局截图快捷键，关闭后恢复。

### 设置快捷键与外观

点击主窗口右上角 **设置**（或在主窗口按 **Ctrl + 逗号**），在原窗口中进入设置页。点击对应快捷键的按键区域，再按新的组合键，最后点击 **保存并返回**（也可按 Ctrl + Enter），立即生效。支持 Ctrl / Alt 组合键（可加 Shift）、F1–F24 或 Print Screen。按 Esc 取消本次录入，Tab 切换控件；行末 **×** 可清除此项快捷键。“恢复默认”需要保存后才生效。

点击 **返回截图**、**取消**，或在未录入快捷键时按 Esc，会放弃未保存的修改并返回截图工作台。原来的预览图片会保留；缩小窗口时设置内容可以滚动，保存与取消按钮固定在底部。

保存时会检查三项快捷键是否重复以及是否被其他程序占用；失败时显示具体项目并保留原配置。编辑设置期间暂停本软件的全局快捷键，关闭设置后恢复。截图快捷键按功能绑定，可将任意支持的组合键分配给区域/窗口、全屏或滚动截图。滚动截图仍按配置的同一个快捷键停止。

外观提供 **跟随系统／浅色／深色** 三项带缩略预览的选择；点击后可在当前页面预览，保存后应用到主窗口与滚动窗口，取消恢复原配色。应用设置保存在程序旁的 `SnapFlow.preferences.json`，与原有 `SnapFlow.settings.json` 滚动选项分开；构建时保留本地两份设置，分发包不包含个人配置。程序目录需可写。

**界面动画** 可单独关闭，保存后会记住。动画遵循 Windows 客户区动画设置，高对比度模式下停用；本软件不修改系统动画设置。动画只用于显示反馈，不增加截图触发等待时间，隐藏截图窗口时会结束尚未完成的页面过渡。旧配置不含此项时采用默认开启，并继续遵循系统设置。

没有上传、录屏、OCR、历史库、自动更新或开机启动入口。滚动选项中原版的“自动上传/保存”在此版本仅执行本地保存。

## 源码与裁剪范围

当前代码位于 `src/`：主程序、`ShareX.ScreenCaptureLib`、`ShareX.HelpersLib`、`ShareX.ImageEffectsLib`。图片效果库与 ImageListView 是正式版原始选区代码的编译依赖，此轮保留依赖，未提供独立图片效果工具入口。

删除了录屏实现、录屏/FFmpeg 窗口、MediaLib 引用。未引入原主程序的上传器、工具、历史库、OCR、浏览器宿主或任务调度。主程序直接调用原版 `RegionCaptureTasks`、`Screenshot` 和 `ScrollingCaptureForm.StartStopScrollingCapture`。

`src/UPSTREAM.json` 记录官方标签、源码下载地址、校验值及改动范围。编辑功能接入前记录了 1,205 个与官方标签逐文件 SHA-256 一致的库源码/资源文件；编辑接入、精简和边界裁剪在其中七个文件加入工具栏宿主扩展、编辑器工具限制、裁剪交互和保存对话框修正。修改了滚动管理器的输入/停止判定、文档边界识别、拼接比较范围与接缝位置，以及滚动窗体的状态属性、异步选区调用和创建回调；新增一个浏览器文档边界辅助类。选区窗体仅新增可选的编辑器工具栏事件；工具栏为宿主设置按钮名称并调用该事件，未订阅时保留原行为。图片保存对话框支持指定父窗口，并只在保存成功时返回路径。裁剪、历史记录、图像编码与原生截图算法未改；拼接中的原始逐行搜索循环保留。主程序连接本地保存回调，将该按钮显示为“保存图片”，并在显示滚动窗体前注册关闭事件。

先前开发版和独立原型仅归档于工作区 `artifacts/`，不参与构建，不包含在发布包或对应源码包中。

## 构建与测试

使用支持 .NET 9 的 SDK（本机 .NET SDK 10.0.302），在项目根目录运行：

```powershell
.\build-capture.ps1
```

输出程序目录、便携包和对应源码包。普通截图测试：

```powershell
.\build-capture.ps1 -DesktopSmoke
```

Edge 回归会操作鼠标和滚轮：先在独立 Edge 窗口打开 `tests/edge-article.html` 并回到顶部，然后运行：

```powershell
dotnet build src/ShareX.Roll.Tests/ShareX.Roll.Tests.csproj -c Release -p:Platform=x64
.\src\ShareX.Roll.Tests\bin\Release\win-x64\ShareX.Roll.Tests.exe --edge
```

设置回归使用 `ShareX.Roll.Tests.exe --settings`：检查实际设置入口、取消、重复与系统占用、保存失败、重启读取、明暗模式，以及通过 Windows 输入触发自定义全屏快捷键。测试会短暂显示应用窗口并发送该自定义按键，不操作浏览器；原测试配置会在结束后恢复。

边界裁剪交互回归使用 `ShareX.Roll.Tests.exe --edge-crop`（可加 `--dpi96`），会短暂操作测试窗口中的鼠标，验证顶部、左侧和角点拖动、确认、取消、撤销及逐像素结果。需在允许桌面输入的会话运行；加 `--simulate-input` 可通过隔离的节点输入状态验证同一拖动与裁剪流程，不发送桌面鼠标输入。

编辑窗口回归使用 `ShareX.Roll.Tests.exe --editor`；加 `--dpi96` 可检查 100% 布局。检查编辑入口、最小宽度布局、原图副本、快捷键暂停与恢复、裁剪逐像素结果、撤销／重做、五种导出编码、取消导出、应用与放弃修改，以及长图缩放。测试图片与界面渲染位于 `artifacts/image-editor/`。

界面与动画回归使用 `ShareX.Roll.Tests.exe --ui`；加 `--dpi96` 可检查 100% 布局。检查左侧操作和预览布局、明暗配色、最小窗口、动画中间帧、结束后释放资源、减少动态效果及连续导航。实际截图与日志位于工作区 `artifacts/hig-refresh/`，不放入发布包。

`ShareX.Roll.Tests.exe --motion` 检查即时按下反馈、快速反向时的连续性、动画范围与结束、减少动态效果以及隐藏窗口后的清理。动画优化的日志和控件渲染帧位于 `artifacts/motion-polish/`。

`ShareX.Roll.Tests.exe --animation-performance` 检查透明度合成的像素误差、裁剪与坐标变换、预览副本清理、完整原图保留，以及明暗页面的首尾与中断连续性；可加 `--dpi96`。性能数据与回归日志位于 `artifacts/animation-optimization/`。帧间隔记录属于 UI 绘制时序，不等同屏幕实际呈现 FPS。

`--merged-capture` 验证合并入口的拖动、单击窗口、取消与旧快捷键迁移。`--workspace-preview` 使用独立本地测试窗口验证滚动完成、取消、停止、连续截图、复制、保存像素和结果资源生命周期。`--lifecycle` 验证取消、再次启动和停止流程；`tests/verify_article.py` 可将结果与独立浏览器整页参考图逐段比对（仅额外图像核对需要 Pillow、numpy）。实际验证和限制见 [VALIDATION.md](VALIDATION.md)。

`--explorer` 会生成并打开包含 180 个测试文件的独立目录，检查实际滚动百分比和最后一屏像素；配合 `--move-away` / `--move-midway` 验证鼠标移开。`--no-scroll` 检查静态窗口不会误报成功。测试不会删除用户文件。

在获得当前浏览器使用授权后，可用 `--live-capture --target-hwnd <窗口句柄>` 验证独立滚动文档；`--live-reference` 只滚动章节目录，生成独立可见行参考图，随后用 `python tests/verify_chapter_rows.py --expected <节数>` 比对。测试恢复原滚动位置，不打开课程链接。真实页面截图和参考图仅保存在工作区 `artifacts/`，不随发布包或源码包分发。

`--stitch-regression` 不操作桌面，使用独立生成的完整图像验证无悬浮控件、两种宽度的双侧固定控件及最后较小滚动步长的逐像素完整性。真实课程列表可用 `--live-card-reference --target-hwnd <窗口句柄>` 采集封面和标题参考图，随后用 `python tests/verify_visible_items.py --expected-cards <课程数>` 比对；该测试针对已授权的学习通个人空间课程布局。

## 图片编辑界面与动画

编辑窗口将复制、保存、导出及应用置于上方，标注工具独立成排，统一线条图标和选中边框；窄窗口通过更多菜单保留其余工具。裁剪继续拖动图片边界，使用工具栏确认/取消或 Enter/Esc。支持深浅主题与高 DPI。按钮悬停、按压和工具切换采用短反馈动画，遵循应用与 Windows 动画设置；画布空闲时停止重绘，拖动直接跟手。

界面与空闲刷新回归：ShareX.Roll.Tests.exe --editor-chrome（可加 --dpi96）；原有 --editor 与 --edge-crop --simulate-input 覆盖裁剪、标注、历史及导出。

编辑器裁剪框使用细蓝色边线及条形边缘手柄；长截图可缩小到 20% 以下完整显示，裁剪时缩小窗口会重新适配。拖动上、下居中的手柄调整高度；再次点击裁剪可恢复完整视野并保留已选边界。裁剪外区域变暗，拖动时显示三等分参考线。

工具栏前部的“颜色”提供 8 种常用色和自定义选色。先选颜色再绘制，或选中已有批注后换色；画笔、形状、文字、序号和高亮会修改各自对应的颜色，已有批注换色支持撤销／重做。“填充”单独调整形状填充，更多样式仍在样式菜单内。

放不下的工具通过右侧三点“更多工具”入口收纳，展开为带图标和名称的单列菜单，按功能留白分组，支持深浅主题、键盘遍历和原有编辑子菜单。关闭菜单或调整窗口后恢复工具栏布局。

`ShareX.Roll.Tests.exe --annotation`（可加 `--dpi96`）检查常用色、自定义色、取消选色、十类批注的实际输出像素及换色历史。`--annotation-physical` 使用真实鼠标检查已有矩形批注换色。
